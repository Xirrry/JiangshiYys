# 僵尸痒痒鼠

作者：昔乃 · QQ：3499049029 · 邮箱：xiryy@qq.com

Windows 阴阳师桌面版角色启动工具，使用 Python、Vue 3 与 WebView2。

## 思路由来

本软件的设计思路受 [平安志](https://member.xlhome.de5.net) 启发，感谢平安志带来的灵感。

## 下载与运行

使用前请阅读本页的[使用说明与免责声明](#使用说明与免责声明)。

在 [Releases](https://github.com/Xirrry/JiangshiYys/releases) 下载 Windows x64 完整包，解压后运行「僵尸痒痒鼠.exe」。需要 WebView2 Runtime 和已安装的游戏客户端。使用说明内置于软件，也可阅读仓库中的 [用户使用手册](用户使用手册.md)。

v9.55 为测试版本。IP 代理和设备接口功能未经完整测试，不保证可行性、兼容性或稳定性。检测通过不代表所有游戏流量已代理，设备功能不保证形成独立硬件身份。

## 功能

- 独立角色缓存、平安志同步、角色分组及多视图管理。
- 多个启动方案共享角色引用，支持排序、窗口排列、启动延迟和关闭。
- 全局、角色与方案三级声音、动画及画质设置。
- 内置单角色 TCP 代理和老鱼专业版 API 对接。
- 默认关闭的设备接口实验与按需状态核验。
- 游戏目录检测、已移除角色永久删除并清理私有缓存。
- 道馆全资源记录、批量邮件读取、蓝票同步、合区去重及周报/月报导出。
- 独立运行窗口页：不限制启动来源，支持定位、网格、错落及拖动排列。

邮件读取会在游戏进程加载临时组件，存在客户端兼容性与账号处罚风险，不保证账号安全。

设备与代理入口默认隐藏：在「关于与作者」页 5 秒内点击版本号 7 次，可在本次运行中显示或隐藏。隐藏不改变已有启动配置。

## 源码运行

使用 Windows x64、Python 3.12、Node.js 与 npm：

```powershell
python -m pip install -r requirements.txt
npm --prefix frontend ci
npm --prefix frontend run build
python app.pyw
```

依赖可安装到当前 Python 环境，或通过 `--target vendor` 安装到本项目。硬件及代理原生 DLL、WinDivert 驱动随源码提供；普通源码启动不会自动加载驱动。首次使用请在界面配置游戏目录，不需要复制开发者的 data。

## 软件内更新

「关于与作者 → 软件更新」支持 GitHub Releases 检查、可关闭的启动检查、版本说明、下载进度和 SHA-256 校验。支持「下载并安装」：退出游戏、保存方案后，原生助手切换版本并保留旧程序备份，data 整体移动保留，完成后自动重新启动。v9.49 及更早版本首次换成 v9.50 仍需手动解压。

## 复制 data 的兼容修复

v9.51 起在启动角色时检查资源目录：复制成普通文件夹、或指向旧游戏位置的链接，先在角色目录内改名备份，再重建当前游戏资源链接。账号登录缓存保留，不删除原内容；正确链接不重复备份。迁移前先退出游戏和启动器，避免覆盖未备份的重要数据。

v9.55 起最低画质预设不修改抗锯齿开关或档位，保留游戏自身设置。若旧版曾关闭，请在游戏中开启一次。
