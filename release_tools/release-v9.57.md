# v9.57 日常清单、冷却提醒与窗口排列

- 新增每日与每周日常清单，按角色记录任务进度；支持分组、折叠、组内排序、档案移除与恢复。移除档案后停止提醒，已有记录保留，再次读取不会自动加回。
- 支持每角色监控开关及重要程度配置，并可通过任务设置快照应用给多个角色。不提醒的任务不计入待办与完成率，待领取不催领。
- 接入祈愿、寮三十、寮资金、每日礼包、协战、地域鬼王、分享、秘闻、斗技、真蛇、永生之海、六道等进度；显示任务相关的次数与资源信息。部分数据需先在游戏中加载或刷新后才能读取。
- 新增好友寄养、自己的结界卡、师徒守护历练、收徒冷却与历练点数监控；兰契碎片交换按客户端截止时间显示冷却，支持手机交换后重新登录读取。
- 阴阳寮活动区分寮开启次数与个人宴会参与次数，麒麟按个人挑战和伤害判断。阴界之门按周五至周日、麒麟按周一至周四显示开放日。
- 接入上周储存奖励的剩余提醒。逢魔 Boss 改为按实际已打与可打总次数判断完成，支持补打第二次，修复打一场就提前完成的问题。
- 读取操作在后台执行，不同游戏窗口并发读取；单角色读取、读取工具栏与页面内部滚动统一整理；支持按窗口名选择读取，批量结果仅显示简短摘要，详细信息按需展开。
- 悬赏默认选择北京时间当前轮次，移除全部轮次筛选；重点视图对匹配角色增加快捷启动，隐藏被分享的协作任务；周商店独立页面暂不展示，保留清单中的重要兑换项。
- 运行窗口支持自动列数、按方案全选、按方案正反向错落；可配置起始坐标及横纵偏移，并分别保存方案参数。
- 新增首次使用须知、账号风险及免费声明，主动勾选并保存同意记录后才进入主界面。取消寄养到期的大段弹出消息，清单状态保留。

## 下载与升级

下载 Windows x64 ZIP，完整解压后运行“僵尸痒痒鼠.exe”。本软件完全免费，无需激活码、会员或付费授权。请通过项目发行页获取，勿向倒卖者付款。

升级前保存方案并备份 data；普通游戏窗口可保持运行，使用软件代理的游戏请先关闭。发行包不含账号缓存、个人记录或代理凭证；个人配置、记录与同意记录保存在软件目录下。

## 功能边界

读取与提醒属于实验功能，结果以游戏界面为准。缺失或未加载的数据不应解释为已完成；读取失败会保留既有记录。读取不自动执行战斗、交换或领取。

客户端读取、代理和设备隔离可能触发游戏安全检测，存在账号限制、封禁或虚拟财产损失风险，不保证账号安全。使用前请阅读软件中的使用须知。未完成跨电脑游戏兼容性测试。
