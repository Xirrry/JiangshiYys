## 下载与升级

下载 Windows x64 ZIP，完整解压后运行“僵尸痒痒鼠.exe”。升级前保存方案并备份 data；普通游戏窗口可保持运行，使用软件内代理的游戏需先关闭。不要覆盖仍在运行的安装目录。

读取类功能为实验功能，只读取当前客户端已加载的数据，可能需要先打开对应游戏面板。首次记录前已领取或未加载的数据无法保证补录；读取结果应与游戏界面核对。邮件发送日作为记录日期。

读取使用进程内临时组件，不自动领取奖励、执行战斗或购买商品，仍存在客户端兼容性及账号处罚风险，不保证账号安全。代理与设备隔离同为实验功能。未完成跨电脑游戏兼容性测试。

发行包不含账号缓存、个人记录数据库或代理凭证。
